NEW FUNCTIONS:
- Update-PlaylistDisplay()
  * Displays 7 lines showing ±3 files around current position
  * Current file: Bold + DarkBlue text + LightGreen background
  * Uses SelectionBackColor for highlighting

- Save-SessionLog()
  * Saves to [004-CBZ_Sorter_SESSIONLOG].txt
  * Format: Date, Time range, Duration, Stats
  * Called automatically on Quit

MODIFIED FUNCTIONS:
- Open-File()
  * Added call to Update-PlaylistDisplay()

- Refresh-FileList()
  * Added call to Update-PlaylistDisplay()

EVENT HANDLERS:
- MouseMove (playlist hover effect)
  * Tracks line index under mouse
  * Redraws playlist with SkyBlue highlight on hover
  * Current file shows SkyBlue when hovered, LightGreen otherwise

- MouseLeave (clear hover)
  * Resets $script:lastHoveredLine to -1
  * Calls Update-PlaylistDisplay() to clear hover effect

- MouseClick (jump to file)
  * Extracts filename from clicked line
  * Strips >>> prefix if present
  * Calls Open-File with "Playlist Jump" reason
